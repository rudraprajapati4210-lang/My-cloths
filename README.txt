# My Wardrobe Outfit Builder

This is the first app version of your personal wardrobe builder.

Features:
- Select a top and see all bottoms.
- Select a bottom and see all tops.
- Show all clothing combinations.
- Outfit lineup: top -> bottom -> shoes -> watch -> kada -> extra.
- Add new clothing items with a photo.
- Custom items are stored in the browser.
- Installable as a PWA when hosted on HTTPS.

## iPhone installation
1. Put this whole folder on a HTTPS web host (for example GitHub Pages).
2. Open the site in Safari.
3. Tap Share -> Add to Home Screen.
4. Open the new My Wardrobe icon like an app.

Important: iOS does not reliably install a PWA directly from a local ZIP/Files HTML file. The folder needs to be served by a web address.
